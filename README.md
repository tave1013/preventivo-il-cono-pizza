# Preventivo Pizzeria

## Setup in 2 passi

```bash
npm install
npm run dev
```

Apri [http://localhost:3000](http://localhost:3000) nel browser.

## Deploy su Vercel

```bash
npx vercel
```

## Struttura
```
app/
├── layout.jsx   → root layout
├── page.jsx     → preventivo interattivo
└── globals.css  → stili base
```
